# 开发发布与上架

## 开发

Node25、TypeScript、React与公开河图SDK；npm ci后执行npm run build、npm run check、npm run test:unit。真实机器和工作面分别由test:machine与test:ui运行。包内Skill用skill-creator校验，文档链接及Mermaid实际渲染。

## 版本与制品

首次完整版本v0.1.0。不可变Tag对应源码提交；运行包包含manifest、后端、前端、功能清单、Skill、许可及来源。发行附归档摘要、解压包摘要、release-integrity与固定验收回执。公开后重新下载核验，不移动历史标签。

## 上架与生态

GitHub为源码与发行Owner，河图插件中心收录固定版本、来源、摘要、最低宿主及实际平台范围。专业清单归插件，宿主只维护发现入口。官网作者指南解释目标和审阅方式，开发合同留在本包docs。

## 安装验收

公开CLI固定包检查与安装，原键恢复；既有Codex连接热发现同包Skill，启停与卸载重装不丢历史。覆盖本机、不备份；核对无关插件摘要保持。正式宿主与源码构建、平台运行和文学/媒体质量分别声明。


## 开发者执行入口

先更新本包01～06的受影响合同，再实现领域和用例；专业动作同步manifest、功能清单、包内Skill和正反例，不向宿主清单重复登记。

```bash
npm ci
npm run build
npm run check
npm run test:unit
node scripts/verify-docs.mjs
npm run package
```

构建读取contracts并生成静态校验器与运行包；受管Node权限模式装载测试确保不依赖运行时动态编译。dist是待检查的目录包，output中的tgz是发行归档，二者分别核验摘要，不能混用。

## 正式安装验收

acceptance-lock.json固定正式宿主源码、签名归档摘要和本包内容摘要。工作流下载已公开宿主并检查Developer ID、Gatekeeper和公证，不编译替代宿主；随后运行真实MCP/CLI与Electron，保存分阶段结果、实际工作面与导出文件。

```bash
gh workflow run installed-acceptance.yml --repo wordflowlab/hetu-reader-review --ref main
```

本机重复验收使用新的HETU_ACCEPTANCE_DIRECTORY保留旧失败；HETU_DOWNLOAD_DIRECTORY可复用已经独立校验的下载。仅在Applications安装版本及签名已核对后使用HETU_REUSE_APP=1，不覆盖未知运行实例。开发源码测试与正式签名包验收分别记录。

## 发布与收录合同

1. 锁定运行包，确认单元、机器、界面和同批联合旅程的包摘要一致。
2. 文档记录实际平台、未验证范围、失败及修复，不把模拟素材当作创作品质认可。
3. 创建不可变v0.1.0标签和GitHub Release，上传tgz、归档摘要、release-integrity、acceptance-lock及验收回执。
4. 从公开Release重新下载，核验归档与解压内容双摘要；未知发布先回读原标签和附件，禁止覆盖公开版本。
5. 插件中心登记确切源码、下载URL、两类摘要、最低宿主、实际平台和证据；作者指南呈现目标及审阅方式。
6. 使用公开入口安装后，原Codex连接重新发现、读取同包Skill并执行专业动作；保留无关插件及作者作品。

专业升级沿本包格式和版本推进，保留旧修订；宿主API仍由宿主Owner维护，不将内部文件布局作为接入合同。
