# 开发发布与上架

## 开发

Node25、TypeScript、React与公开河图SDK；npm ci后执行npm run build、npm run check、npm run test:unit。真实机器和工作面分别由test:machine与test:ui运行。包内Skill用skill-creator校验，文档链接及Mermaid实际渲染。

## 版本与制品

首次完整版本v0.1.0。不可变Tag对应源码提交；运行包包含manifest、后端、前端、功能清单、Skill、许可及来源。发行附归档摘要、解压包摘要、release-integrity与固定验收回执。公开后重新下载核验，不移动历史标签。

## 上架与生态

GitHub为源码与发行Owner，河图插件中心收录固定版本、来源、摘要、最低宿主及实际平台范围。专业清单归插件，宿主只维护发现入口。官网作者指南解释目标和审阅方式，开发合同留在本包docs。

## 安装验收

公开CLI固定包检查与安装，原键恢复；既有Codex连接热发现同包Skill，启停与卸载重装不丢历史。覆盖本机、不备份；核对无关插件摘要保持。正式宿主与源码构建、平台运行和文学/媒体质量分别声明。
