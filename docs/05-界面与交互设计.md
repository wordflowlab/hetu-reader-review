# 界面与交互设计

## 信息架构

紧凑顶栏提供返回、当前专业方案、刷新与一个高强调“让AI处理”。专业页签为：试读版本、读者与覆盖、反馈与分歧、处理决定、接续创作。进入独立插件页时复用宿主最大化工作面，保留返回位置。

作者先阅读专业成果和依据，按对象提意见；复杂结构由Agent准备。界面不以JSON作为默认展示，不要求填写模型参数。高级编辑保留并在CAS冲突时保留本地输入，显式核对新版后再保存。

## 视觉规范

复用河图Radix纸色、玉色与山水灰，静止连续渐变、轻透表面、细边框及四档以内字号。正文、输入及决定面稳定实色。浅暗与减少透明度分别测试，不能用关闭媒体查询掩盖渐变缺失。

## 交接与恢复

每页AI入口包含当前插件、精确作品、固定对象和具体目标。来源/图像/声音错误局部显示，旧成果仍可读；未知写入先回读原键。关页前保存恢复缓冲，返回保持上下文，撤权或停用按宿主合同降级。
