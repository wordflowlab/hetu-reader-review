# 试读工作台产品需求

## 背景与第一性原理

作者持续积累的作品和判断，比某次生成的文字或界面存活更久。外部Agent擅长理解和生成，固定引用、版本、范围及文件处理适合确定性软件。重复要求模型重建结构会增加上下文和等待，但本产品不承诺固定token节省比例。

把固定试读版本、不同读者意见和修改决定组织成可复核的多轮过程。 需要长期专业状态和可视化审阅，适合作为按需安装的插件；核心只持有通用创作事实。

## 用户与目标

小说作者、编剧、漫画作者及音频创作者通过现有Agent对话完成准备和操作，回来检查实际成果。作者可直接编辑，但不必手工重复录入已说过的信息。

## 首版完整范围

试读包、读者、提交、原始意见、处理决定；固定读取、增量维护、检查、比较、可恢复写入、JSON/Markdown/HTML报告、专业成果导出、包内Skill及同连接热发现。

完整流程：选择固定阅读范围→导出离线试读包→读者本地填写→预览反馈文件→固定导入→聚合分歧→作者决定→新稿复核。

## 边界与非目标

离线包不自动发送或上传。真实读者和Agent模拟分开，模拟意见不计真实人数或满意度。反馈固定包摘要与选区序号，原始意见保持，处理决定另存；新版不静默套旧坐标。包内JavaScript只维护本机表单及下载JSON，嵌入内容转义，不执行反馈中的代码。

不复制宿主正文、正式设定或版本库，不建设聊天和多Agent调度，不含发布、投放和运营。专业状态和候选不等于采纳或定稿。
